# Dashboard runtime repair and current release audit · 3 November 2026

## Failure and repair

The authenticated production dashboard at source `521b6100` returned its shell and data but displayed `__name is not defined` and empty views. The Worker compiler's name-preservation helpers had entered functions subsequently copied to browser JavaScript through `Function.toString()`. Their server helper was unavailable in the browser. Source-only rendering tests missed this boundary.

`build_dashboard_client.mjs` now captures the shared model functions in plain Node before Worker compilation. The generated `dashboard-client-models.mjs` exports browser source as data. Worker compilation can no longer inject runtime helpers into that string. The shared growth models remain the canonical logic; a synchronization test prevents stale generated code.

The normal browser harness now compiles the actual UI module with name preservation and minification before rendering it. Three fast regression tests also execute the compiled model code with and without minification, in a fresh context without Worker helper globals. The build pipeline regenerates the client source before its tests.
